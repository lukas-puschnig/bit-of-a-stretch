Bilder für Katalogübungen, benannt nach der Übungs-ID (z. B. `pigeon.webp`). Sie werden beim
Build automatisch zugeordnet.

- `*.svg` sind generierte Platzhalter: `npm run images` erzeugt sie aus `scripts/figures/poses.mjs`.
- Ein Rasterbild (`.webp`, `.png`, `.jpg`) mit gleicher ID hat Vorrang vor dem Platzhalter.

Vorgaben für neue Bilder: `docs/exercise-images.md`.
